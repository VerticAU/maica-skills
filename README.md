# Maica skills

Agent skills for Maica teams, imported into Paperclip as a skill source.

| Skill | Use |
|---|---|
| `skills/maica-document-formatting` | Maica's visual style for Word, Excel and PowerPoint deliverables |
| `skills/maica-ui-design` | Maica's visual identity for web pages, Salesforce-hosted UI and HTML email |

Each skill is a folder with a `SKILL.md` and its supporting files. Changes pushed to `main` reach Paperclip agents when the skill source updates.

This repository is the source of truth for these skills. Copy any changes made to the claude.ai organisation versions here too.
